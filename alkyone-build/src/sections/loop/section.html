1 The system · concept

One loop that closes.

Alkyone is a concept for a single closed loop: notice, send, alert, acknowledge, learn. Every step has a fallback, so a quiet moment is never just assumed to be fine.

  3. 3 · Alert

    The ring buzzes in patterns that scale: one soft buzz for routine, a firm pattern for needs attention.

    If it fails: the firm pattern repeats until someone acknowledges it.

  4. 4 · Acknowledge

    Tap the ring. The patch and the app are told, and the buzzing stops. That closes the loop.

    If it fails: with no answer, the alert keeps repeating. Passing it to a second person is exploratory.
